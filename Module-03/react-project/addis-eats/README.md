# Addis Eats

Addis Eats is an Ethiopian restaurant web application built with React.

It features:

- Dynamic menu browsing with categories and search
- Dish details with spice-level selection
- Shopping cart with quantity controls and persistence
- Checkout and delivery options
- User registration, login, and protected routes
- Form validation with React Hook Form and Zod
- Client-side state management with Zustand
- Responsive design and lazy-loaded pages with error handling

## How to Run

1. Clone the repository and navigate to the project directory.
2. Open a terminal in the project directory and run `npm install`.
3. Start the development server with `npm run dev`.
4. Open the local URL shown in the terminal in your browser.
