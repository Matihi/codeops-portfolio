### How to run the api

1. copy the `campus-events-api` folder
2. install Node.js version specified in `.nvmrc` file directly or through nvm
3. open a terminal in the `campus-events-api` folder and run `npm install` to install dependencies
4. install `REST Client` extension in vscode
5. run `npm run start:dev` to start NestJs
6. open the `requests.http` file
7. click on `Send Request` above each request to get a response
