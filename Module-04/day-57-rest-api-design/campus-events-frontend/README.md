This project is a frontend and backend integration.

Technologies used: nextjs, nestjs.

Installation instructions: copy the `day-57-rest-api-design` folder, open both sub-folders and open terminals for both and run `npm install` then `npm run start:dev` for the first and `npm install` then `npm run dev` for the second.

Features: view upcoming events, view all events, view event details, view session details and create event.
