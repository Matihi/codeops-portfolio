# Addis Eats

Addis Eats is a simple Ethiopian restaurant ordering web app. Users can browse the available dishes, search for specific dishes, add items to their order, adjust their cart, and place an order through the checkout form.

## Features

- Browse Ethiopian dishes
- Search the menu by dish name
- Add dishes to the cart
- Remove dishes from the cart
- Automatically calculate the order total
- Persist the cart using `localStorage`
- Validate the checkout form
- Display an order confirmation after placing an order

## Data Source

The menu data is loaded from the local JSON file:

```text
./data/menu.json
```

### How to run it

Download the module-project directory and open index.html
